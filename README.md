# 2D_SFD_Transonic_Flow_Solver

2次元スーパクリティカル翼まわりの圧縮性流れをブラウザ上で時間発展させ、翼型設計、流れ場、空力係数、収束履歴を同時に観察する教育・概念設計用CFDシミュレーターです。

数値計算核はC++で実装し、WebAssemblyとしてブラウザ内で実行します。生成済みの`cfd-core.js`と`cfd-core.wasm`を同梱しているため、通常の起動時にビルド処理は不要です。

## 起動と停止

プロジェクトのディレクトリで次を実行します。

```bash
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000/` を開きます。

起動したターミナルで `Control + C` を押すと停止します。別のターミナルから停止する場合は、使用中のPIDを確認してから終了します。

```bash
lsof -nP -iTCP:8000 -sTCP:LISTEN
kill -TERM <表示されたPID>
```

JavaScript更新後に古い表示が残る場合は、macOSでは `Command + Shift + R` で強制再読み込みしてください。

## 画面構成

画面は同じ幅の縦3列で構成され、すべての結果が同時に更新されます。

### 翼型ジオメトリー

- 基準翼型と現在翼型の重ね合わせ
- キャンバー線、最大翼厚、最大キャンバー位置、断面積
- 翼型全体図とは独立した前縁 `0–12%c` の拡大図
- NACA 4桁翼型とスーパクリティカル翼型プリセットの一括選択
- 翼厚比、前縁半径係数、キャンバー、キャンバー位置、上面平坦度、下面アフトローディングの微調整
- 各パラメータはスライダーと半角数字入力のどちらでも指定可能

### 空力・流れ場

- 迎角: `−10°～50°`、`0.5°` 刻み
- Mach数: `0.30～1.20`、`0.01` 刻み
- Reynolds数: `1.0×10⁴～1.0×10⁷`（対数スライダー、既定 `50000`）
- 迎角・Mach数・Reynolds数はスライダーと半角数字入力のどちらでも指定可能
- 摩擦抗力モデル: 平板乱流・平板層流・摩擦なしの切り替え
- Mach、Schlieren、速度、圧力、密度、流線の切り替え
- 翼面Cp分布、`Cl`、`Cd`（圧力成分と摩擦成分の内訳付き）、`Cm,1/4`、圧力中心
- 流線表示: 背景コンターと格子線を表示せず、翼面適合O格子の外周楕円内だけに、セル中心速度からRK2積分した流線を局所Mach数で着色して流向矢印付きで表示
- 白い破線: `M = 1` 等値線（流線表示を除く）
- `SHOCK` マーカー: 上面圧力上昇から検出した衝撃波位置

### 収束ログ

- iterationに対する保存量更新量 `ΔU`
- `Cl`、`Cd`、`Cm,1/4` の履歴
- 上面衝撃波位置 `xshock/c` と最大局所Mach数
- 直近100 iterationの `Cl` 変化量

履歴は10 iterationごとに記録します。迎角、Mach数、Reynolds数、翼型形状を変更すると、流れ場と履歴が再初期化されます。摩擦抗力モデルは後処理項のみを変えるため、流れ場は初期化しません。

## 翼型プリセット

プルダウンから次の翼型を一括選択できます。選択すると形状パラメータ、流れ場、収束履歴が更新され、その後は各スライダーで微調整できます。

- NACA 0009、0012、0015、2412、4412
- Supercritical baseline 12%
- NASA SC(2)-0412相当、SC(2)-0612相当
- RAE 2822相当

NACA 4桁翼型は標準の厚さ分布と平均キャンバー線を使用した閉後縁型です。SC(2)系とRAE 2822は公開座標点の完全な複製ではなく、現在の翼厚・キャンバー・上面平坦化モデルによるパラメトリック近似です。定量比較では実座標データを使用してください。

## 翼型パラメータ

| パラメータ | 範囲 | 刻み | 基準値 |
|---|---:|---:|---:|
| 翼厚比 `t/c` | 8–18% | 0.1% | 12.0% |
| 前縁半径係数 | 0.6–1.6 | 0.05 | 1.00 |
| 最大キャンバー | 0–6% | 0.1% | 2.2% |
| 最大キャンバー位置 | 25–65%c | 0.5%c | 42.0%c |
| 上面平坦度 | 0–2% | 0.1% | 1.0% |
| 下面アフトローディング `lowerBias` | 0–0.8%c | 0.05%c | 0.35%c |

前縁半径係数は厚さ分布の平方根項を変え、後縁厚がゼロのままになるよう線形項を補正します。形状変更後は「格子再生成」を押すと翼面適合格子へ反映されます。

`lowerBias`は下面の中後方を翼弦長で無次元化した量だけ掘り下げる設計変数です。下面座標へ次の変位を減算し、前縁側を保ったまま後部下面キャンバー（アフトローディング）を付加します。

```text
Δy_lower = lowerBias · sin(πx) · smoothstep(0.15, 0.65, x)
```

遷音速設計で上面衝撃波を抑えながら揚力を確保するための主要な設計自由度ですが、この簡略ソルバーでは最終的な効果を格子収束試験や高忠実度CFDでも確認してください。

## 数値入力

翼型パラメータと流れ場パラメータは、スライダーの横にある数字入力欄へ直接値を書き込めます。入力欄とスライダーは同じ値を共有し、片方を操作すればもう片方も追従します。

- 確定は `Enter` キー、またはフォーカスを外したときです。入力途中では計算は再初期化されません
- 全角数字と全角記号は半角へ自動変換します（`１４．５` → `14.5`）
- 桁区切りと空白は無視します（`250,000` → `250000`）
- 指数表記を受け付けます（`2e5` → `200000`）
- 範囲外の値は上限・下限へ丸めます（Mach数に `2.0` を入れると `1.20`）
- 各パラメータの刻みへ丸めます（迎角に `3.7` を入れると `3.5`）
- 数値として読めない文字列は入力前の値へ戻します
- `↑` `↓` キーで1刻みずつ、`Shift` を併用すると10刻みずつ増減します

Reynolds数の `↑` `↓` は `1000` 刻みです。

ドラッグ操作中はスライダーと数値表示を即時更新し、翼型パラメータでは2D形状プレビューもフレーム単位で追従します。設定値はこの時点ではCFDへ適用されず、格子と流れ場も更新されません。

### 手動計算フロー

1. 翼型ジオメトリー、迎角、Mach数、Reynolds数、摩擦モデル、格子解像度を設定します。
2. 変更があると状態が「格子更新待ち」になり、「計算開始」とリセットは無効になります。
3. 「格子再生成」を押すと、保留中の全設定をまとめて適用し、翼面適合格子と一様な初期流れ場を生成します。
4. 「計算開始」を押すと時間発展を開始します。開始後は同じボタンが「一時停止」になり、一時停止後は「再開」になります。
5. リセットボタン `↻` は、現在有効な条件を変えずに流れ場と履歴を初期化し、「計算開始」前の待機状態へ戻します。

設定変更後は「格子再生成」を押すまで計算を開始できません。これにより、古い格子上で新しい翼型や流れ場条件を計算する不整合を防止します。

## 計算負荷設定

MacBook Airのようなファンレス機で連続運転できるよう、次の3段階を選択できます。格子変更時は流れ場と収束履歴を再初期化します。

| 設定 | 格子 | セル数 | 用途 |
|---|---:|---:|---|
| 省電力 | `96 × 48` | 4,608 | 長時間運転、温度優先 |
| 標準（既定） | `128 × 64` | 8,192 | 翼面分布と負荷のバランス |
| 精細 | `160 × 72` | 11,520 | 衝撃波位置の比較、短時間運転 |

既定の計算速度は`1×`です。1ステップあたり120ms以上の間隔を取り、流れ場描画は160ms間隔に制限します。`2×`と`4×`は計算を速めますが、連続使用時の発熱も増加します。C++/WebAssembly化後もこの間隔を維持し、速度向上分をCPU使用率の低下へ振り向けています。

## 数値モデル

このソルバーは、2次元圧縮性Navier–Stokes方程式の簡略化されたリアルタイムデモです。HLL流束、粘性項、保存量更新、派生場計算はC++/WebAssemblyで実行し、格子生成、翼面サンプリング、描画、UIはJavaScriptが担当します。大きなセル配列はWebAssemblyメモリをJavaScriptの`Float32Array`として直接参照するため、iterationごとの配列コピーはありません。

- 保存変数: `ρ`、`ρu`、`ρv`、全エネルギー `E`
- 既定計算格子: 翼周方向 `128` × 壁面法線方向 `64` の翼面適合O型構造格子
- 格子配置: 翼周方向は前縁の密度を維持しつつ、周期境界となる後縁・後流方向にも集中させた弧長分布。法線方向は翼面側へ伸長配置
- 対流流束: 各曲線格子面の単位法線方向へ評価するHLL衝撃波捕獲流束
- 粘性・熱伝導: 隣接セル中心間距離を用いたLaplacian近似
- 時間積分: 陽的1段時間積分、`CFL = 0.38`
- 気体: `γ = 1.4`、`Pr = 0.72`
- Reynolds数: `Re = 1.0×10⁴ ～ 1.0×10⁷`（既定 `5.0×10⁴`、画面のスライダーで変更）
- 外部境界: 外周2セル層を一様流状態へ固定
- 翼面: 格子面に一致した非貫通・滑り壁の圧力流束

既定の標準格子は翼面に約64セル/片面、総計`8,192`セルを配置します。先の高精細`256 × 112`格子よりセル数を約71%削減しています。曲線格子の面長、法線、セル面積は格子生成時に計算し、保存量更新へ用います。

翼周方向の写像には前縁集中項と前後縁集中項を組み合わせています。前縁付近の間隔をほぼ維持したまま、O格子の周期継ぎ目である後縁直後のセル幅を従来のおよそ半分、後流中央付近を約3割細かくし、後縁圧力回復と後流勾配の解像度を改善します。総セル数と1 iterationあたりの演算量はほぼ同じですが、最小セル幅の減少により同じ無次元時間まで進めるiteration数は標準格子で約14%、精細格子で約21%増えます。

鋭い後縁でO格子が特異になることを避けるため、計算格子だけは後縁に合計約`0.3%c`の微小厚さを与えて正則化しています。画面の翼型線は入力形状を表示します。

翼面条件は非貫通の滑り壁近似です。壁面で質量・エネルギー流束をゼロにしますが、厳密なno-slip境界層は解いていません。

## Cpの取得と表示

翼面が格子面そのものになったため、Cartesian階段境界の面平均は廃止しました。現在は次の方法を使用します。

- 壁面から第1・第2セル中心の圧力を壁面位置へ線形外挿
- 上下面を格子解像度に応じた共通翼弦位置へ再標本化（省電力48点、標準64点、精細80点）
- 衝撃波の圧力跳躍を残す弱い局所平滑
- 衝撃波近傍を除いたCp二階差分RMSによる粗さ診断
- 標準的な空力グラフと同様に、負のCpを上、正のCpを下へ表示

衝撃波検出には、同じ壁面外挿系列の圧力上昇と局所Mach数低下を使用します。Cp表示の平滑系列とは別に、生の外挿値も保持します。

## 空力係数

翼面近傍で取得した圧力を翼面に沿って積分し、圧力合力と1/4翼弦点まわりのモーメントを求めます。基準動圧は無次元一様流に対して `q∞ = 0.5 M∞²` です。

- `Cl = Fy / q∞`
- `Cd = max(Cd,pressure, 0) + Cd,friction`
- `Cm,1/4 = M1/4 / q∞`

`Cm,1/4` は空力の標準慣例に合わせ、頭上げを正としています。1/4翼弦点まわりのモーメントは `Mz = Σ (x−0.25)Fy − y Fx` の符号を反転して求めるため、有キャンバー翼では文献と同じく負値になります。

`Cd` は圧力成分と摩擦成分の和です。圧力成分は翼面圧力積分から求めた値を緩和処理したもので、非粘性計算では本来ゼロ近傍のため、実質的に数値粘性の大きさを表します。摩擦成分は流れ場から求めた量ではなく、Reynolds数だけで決まる平板近似の後処理項です。負の圧力抗力はゼロに切り捨ててから加算します。画面のCD欄には `圧力 0.0000 + 摩擦 0.0000` の内訳を表示します。

係数表示には、5 iterationごとに得られる値への緩和処理を適用しています。摩擦成分は緩和せず、モデル変更と同時に反映されます。

## Reynolds数と摩擦抗力モデル

Reynolds数の範囲は `1.0×10⁴～1.0×10⁷` です。スライダーは対数目盛で、仮数を1桁に丸めた `1.0`、`1.3`、`1.6`、…、`7.9` ×10^k のきりのよい値を取ります。数字入力欄は範囲内の任意の整数を受け付けるため、`250000` のような値も直接指定できます。Reynolds数は流れ場の拡散項 `μ = max(M∞, 0.3) / Re` と摩擦抗力の両方に効くため、変更すると流れ場と収束履歴を再初期化します。

摩擦抗力モデルは翼弦Reynolds数に対する平板近似で、`Cd` の摩擦成分だけを決めます。流れ場は変化しないため、切り替えても再初期化は行いません。

| モデル | 式 | `Re = 5×10⁴` での値 |
|---|---|---:|
| 平板乱流（既定） | `Cf = 0.074 / Re^0.2` | 0.0085 |
| 平板層流 | `Cf = 1.328 / √Re` | 0.0059 |
| 摩擦なし | `Cf = 0` | 0.0000 |

いずれも片面平板の値をそのまま加算する簡略式です。実機の翼型抗力を推定する用途には使用できません。

## 圧力中心

表示しているのは空力中心ではなく、圧力合力の作用位置である圧力中心です。`Cm,1/4` が頭上げ正のため、標準的な次式を使用します。

```text
xcp/c = 0.25 − Cm,1/4 / Cl
```

`|Cl| ≤ 0.05` では比が不安定になるため、圧力中心を表示せず `Cl不足` とします。計算結果が翼弦範囲外の場合は数値へ `翼弦外` を付記し、翼型図上のマーカーは表示しません。

圧力中心は迎角によって移動します。薄翼理論でおおむね1/4翼弦に位置する「空力中心」とは異なる量です。

## 収束判定

画面上の `ΔU` は、1 iterationで生じた流体セルあたりの運動量更新量の平均です。収束状態の表示には `ΔU` と直近約100 iterationの `Cl` 変化量を使用します。

- 準定常: `ΔU < 1×10⁻⁵` かつ `Cl`変化量 `< 0.002`
- 収束傾向: `ΔU < 1×10⁻⁴` かつ `Cl`変化量 `< 0.01`
- それ以外: 時間発展中

これは停止条件ではなく表示上の診断です。非定常流や剥離流では係数が一定値へ収束しない場合があります。

## C++ソルバーのビルド

通常利用では生成済みファイルを使うため、この操作は不要です。C++ソースを変更した場合だけ、Emscriptenを導入して再ビルドします。

```bash
brew install emscripten
make
```

生成物は`cfd-core.js`と`cfd-core.wasm`です。画面下部のモデル表示が`C++/WebAssembly`ならC++計算核が使用されています。Wasmを読み込めない環境では既存のJavaScript実装へ自動的にフォールバックし、`JavaScript fallback`と表示します。

MacBook Air M4上のNode.jsマイクロベンチマークでは、標準`128 × 64`格子の時間発展がJavaScript版約`10.37 ms/step`、C++/WebAssembly版約`0.34 ms/step`でした。これは計算核のみの値で、Canvas描画やブラウザの更新時間は含みません。

## 適用範囲と制約

本ソルバーはリアルタイム表示を優先した教育・概念設計用です。

- 翼面位置と法線は格子に一致するが、代数的O格子の非直交性が残る
- 鋭い後縁の格子特異点回避に微小な計算上の後縁厚を用いる
- 滑り壁のため粘性境界層、摩擦、剥離、失速を定量的には再現できない
- 摩擦抗力は流れ場から求めた量ではなく、平板近似による後処理の加算項である
- Reynolds数は流れ場側では拡散項の係数 `μ = max(M∞, 0.3) / Re` にのみ作用する
- 外部境界は非反射境界ではなく一様流固定
- HLL一次精度の数値粘性により、衝撃波が数セルに広がる
- 高迎角、衝撃波境界層干渉、失速後の係数は定性的表示に限定される
- 圧力中心は `Cl` と `Cm` の誤差に敏感で、格子・収束状態に依存する

定量的な解析には、楕円型平滑化を施したC格子、HLLC＋MUSCL/TVD、no-slip壁、RANS/LES乱流モデル、非反射境界、複数段階の格子収束試験が必要です。本ソルバーの結果を耐空性判断や実機設計保証には使用しないでください。
